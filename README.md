# 🌲 GreenNest -- Indoor Plant Website

GreenNest is a modern indoor-plant website designed with a clean green
theme. It showcases indoor plants, plant categories, special offers,
customer reviews, plant-care content, a newsletter section, and a blog.

## 🚀 How to Run

1.  Download or clone the project.
2.  Open the project folder in **VS Code**.
3.  Make sure the image files and `main.js` are in the correct location.
4.  Open `index.html`.
5.  Run the project using **Live Server**.
6.  Open the website in your browser.
